# DreamScape — Cosmic-Themed Interactive Website

An immersive, space-themed multi-page website built to deliver a visually rich, interactive browsing experience using pure HTML, CSS, and JavaScript.

## 🚀 Overview

**DreamScape** invites users to "Explore worlds beyond imagination" through a cosmic-themed interface with a glowing neon aesthetic, animated starfields, and smooth page-to-page interactivity across Home, Gallery, Experience, and Contact sections.

## ✨ Features

- Multi-page layout: Home, Gallery, Experience, Contact
- Custom Canvas-based animated starfield background
- Custom animated cursor for enhanced interactivity
- Scroll-reveal animations for content sections
- Modal overlays for gallery/experience content
- Parallax scrolling effects
- Neon glow typography and space-inspired UI design
- Fully responsive across devices

## 🛠️ Tech Stack

- **Languages:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Graphics:** HTML5 Canvas API (starfield animation)
- **Version Control:** Git & GitHub
- **Editor:** VS Code

## ⚙️ Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/dreamscape.git
   cd dreamscape
   ```
2. Open `index.html` directly in your browser, or run a local server:
   ```bash
   npx live-server
   ```
